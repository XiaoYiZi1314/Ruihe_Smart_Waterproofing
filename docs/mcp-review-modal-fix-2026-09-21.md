# 评价弹窗交互修复（2026-09-21）

## 范围与根因

客户反馈：完工后评价时无法正确选择星级、无法点击评价文本框输入。
真实开发者工具复现：点击服务态度第 2 颗星，reviewScores.attitude 已变为 2，但 showReviewModal 同时变为 false。原遮罩父容器绑定关闭事件，内容区的空 catchtap 不能可靠阻止事件冒泡；重新打开弹窗又把星级重置为 5。与评价接口无关。

## 修复

- detail.wxml：遮罩关闭事件改为独立背景节点，弹窗内容与背景互为兄弟节点，不再在表单祖先节点处理关闭。移除空 catchtap。价格异议弹窗存在相同结构，同步修复。
- detail.wxss：背景绝对定位、面板相对定位并置于背景之上；星星改为 view 点击目标，最小点击尺寸 64 × 72rpx。
- detail.js：限制评分维度为服务态度、施工质量、价格满意度，分数为 1–5 的整数。不改变评价提交接口、订单状态或视频逻辑。
- miniapp/scripts/test-review-modal.js：新增 5 项回归测试。
