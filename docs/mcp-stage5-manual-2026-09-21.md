## 七、验证完成后的发布流程

小程序端验证全部通过后：

1. 微信开发者工具 → **上传**（填写版本号如 1.1.0，备注"阶段五验收修复"）
2. 微信公众平台 → 版本管理 → 将上传的代码设为**体验版**
3. 体验版二维码分发验收 → 确认无误后**提交审核**
4. 审核通过 → **全量发布**
