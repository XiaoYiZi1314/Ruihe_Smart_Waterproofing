# ADR 0005: 后台工单更正与审计

## 状态
已接受

## 背景
原规则禁止管理员修改工单基础信息，也禁止代替客户确认完成。客服实际工作中必须纠正录错的电话、地址、预约时段，改派未完工师傅，并处理现场费用/时间变更。没有审计的话，这些操作会变成改库。

## 决策
1. **允许后台更正**联系人、地址、服务项目、备注、预约、费用和时间节点，但每次必须选择原因、写入变更日志，与业务修改同一事务。
2. **正常流转仍不能代替客户点确认完成**。状态更正白名单里保留「强制完成」，仅用于卡住的工单，必须填原因。
3. **价格仍只协商一轮**：把「价格协商中」更正回待验收时，视为本轮已结束。
4. **未完工改派**后新师傅必须重新接单；施工中改派退回已指派。
5. **师傅现场变更申请**由后台审核。费用申请只有待验收才能直接写入工单。

## 理由
- 小型防水公司客服必须能改错单，但不能悄悄改。
- 强制完成比改库安全，因为它可追溯；仍不是日常验收路径。
- 施工中直接改费用会被师傅完工填价覆盖，所以费用申请只能在待验收落地。

## 后果
- `CONTEXT.md` 中「管理员不能改基础信息 / 不能代替客户确认」改为「更正必须审计；正常流转仍不能点确认完成」。
- 需要执行 `migrate-order-edit.js`（幂等）后功能才可用。
