## 附：已知限制与说明（验收时不算缺陷）

1. **微信订阅消息**：模板 ID 未配置（需在微信公众平台申请），通知会记录到数据库但微信服务通知不发送。管理后台的实时 WebSocket 通知**不受影响**，是本次验收的通知验证途径。
2. **自动任务**：异常工单检测（指派后 24h 未响应）、自动完成（待验收超 3 天）为每小时定时执行，人工验收不等待，代码已在生产运行。
3. **`miniapp-worker/` 目录**：历史备份，验收请使用 `miniapp/`。
4. **评价视频**：评价表单仅支持文字+星级，视频评价字段后端已预留但前端未开放（按需求裁剪）。
5. **图片存储**：本地 `/uploads`（服务器磁盘），云存储 COS/OSS 未接入，接口层已抽象。
6. **开发版设计系统页**：`pages/dev/design-system` 仅开发/体验版可见，正式版自动隐藏。
7. **微信登录 in 开发者工具**：工具中 wx.getUserProfile 可能返回模拟数据，属正常现象；真机预览体验更准确。
