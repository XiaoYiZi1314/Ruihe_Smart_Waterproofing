# ADR 0002: 价格协商单轮机制

## 状态
已接受

## 背景
防水服务的价格通常需要现场评估后才能确定。系统需要在"参考价格"和"最终价格"之间建立一个协商机制，同时避免无休止的讨价还价影响效率。

## 决策
1. **客户预约时填写"期望价格"**（无范围限制）
2. **期望价格对所有人可见**（客户、师傅、管理员）
3. **师傅完工后填写"最终价格"**（细分为上门费、材料费、工时费）
4. **客户可对最终价格提出异议**（需填写理由），工单进入"价格协商中"状态
5. **管理员调整价格后通知客户**
6. **价格仅协商一轮**，之后客户只能确认或线下沟通

## 理由

### 为什么客户要填写期望价格？
- 让客户明确预算，避免完工后价格差距过大导致纠纷
- 帮助管理员和师傅提前了解客户的价格敏感度
- 透明化客户期望，减少信息不对称

### 为什么期望价格对所有人可见？
- 师傅能根据期望价格合理报价，避免虚高
- 管理员能在协商时参考客户预期
- 透明化有助于建立信任

### 为什么价格要细分？
- 防水服务的成本结构清晰（上门、材料、工时）
- 细分价格增加透明度，减少客户疑虑
- 方便后期数据分析和成本优化

### 为什么只协商一轮？
- 防止无休止的讨价还价，影响工单流转效率
- 一轮协商已足够覆盖大部分价格分歧场景
- 真正无法达成一致的，应通过线下深度沟通或升级处理，而非系统内反复操作
- 简化状态机和系统复杂度

## 后果

### 正面影响
- 价格透明，客户信任度高
- 协商流程可控，不会无限循环
- 管理员作为中间人介入，平衡双方利益
- 系统状态流转清晰

### 负面影响
- 客户如对管理员调整的价格仍不满意，只能线下沟通
- 无法在系统内支持多轮协商的极端场景

### 缓解措施
- 提示客户"如对调整价格仍有疑问，请联系管理员深入沟通"
- 管理员在调整价格时应充分考虑双方诉求，尽量一次到位
- 价格协商时客户需填写"异议原因"，帮助管理员了解分歧点
