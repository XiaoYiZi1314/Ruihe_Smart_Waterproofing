# 瑞和防水预约管理系统 - 项目总览

## 项目简介

瑞和防水预约管理系统是一套专为防水施工企业打造的数字化管理平台，包含微信小程序端和Web管理后台。系统实现了客户在线预约、师傅接单施工、管理员统一调度的完整业务闭环。

**核心价值**：
- 提升接单效率：客户在线提交，系统自动通知
- 服务透明化：客户实时查看工单进度
- 管理规范化：所有工单数据集中管理
- 品牌形象升级：专属小程序，专业管理后台

```
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│   客户端        │      │   师傅端        │      │  管理后台       │
│  (微信小程序)   │      │  (微信小程序)   │      │   (Web)         │
└────────┬────────┘      └────────┬────────┘      └────────┬────────┘
         │                        │                        │
         │                        │                        │
         └────────────────────────┼────────────────────────┘
                                  │
                       ┌──────────▼──────────┐
                       │    后端服务器        │
                       │  (Node.js/Java)     │
                       └──────────┬──────────┘
                                  │
                  ┌───────────────┼───────────────┐
                  │               │               │
          ┌───────▼──────┐ ┌─────▼──────┐ ┌─────▼──────┐
          │   MySQL      │ │   Redis    │ │  文件存储   │
```

### 技术栈

**小程序端**：
- 微信原生小程序
- 兼容所有微信版本

**后端服务**：
- 语言：Node.js / Java / Python
- 数据库：MySQL 8.0+
- 缓存：Redis
- 文件存储：腾讯云COS / 阿里云OSS

**管理后台**：
- 框架：Vue 3 + Element Plus / React + Ant Design
- 部署：Nginx静态托管

## 核心业务流程

### 1. 客户预约流程

```
浏览服务 → 选择服务项目 → 查看详情和评价 → 点击"立即预约" 
→ 填写期望价格 → 选择地址 → 上传现场图片（可选）→ 填写备注（可选）
→ 提交工单 → 收到确认通知（包含师傅信息和预计上门时间）
→ 师傅上门施工 → 查看进度 → 确认价格完成 → 评价（可跳过）
```

### 2. 师傅工作流程

```
登录小程序 → 查看指派工单 → 接受/拒绝工单 → 到场开始施工
→ 完工后填写最终价格（上门费+材料费+工时费）→ 等待客户确认
→ 工单完成 → 在个人中心设置上下班状态
```

### 3. 管理员调度流程

```
登录后台 → 工作台查看数据概览 → 处理新工单（确认并指派师傅，填写预计上门时间）
→ 跟踪工单进度 → 处理价格异议（调整价格）→ 处理异常工单
→ 管理服务项目、员工、站点配置 → 导出数据做业务分析
```

### 4. 价格协商流程

```
客户填写期望价格 → 师傅查看期望价格 → 完工后填写最终价格
→ 客户查看最终价格 → [分支]
   ├─ 满意：确认完成
   └─ 不满意：点击"价格有异议"（填写理由）→ 工单进入"价格协商中"
      → 管理员收到通知 → 管理员调整价格 → 客户收到通知并查看
      → 客户确认完成（仅一轮协商）
```
