## 🎯 核心功能流程

### 1. 用户浏览服务流程
```
首页 → 查看热门服务 → 点击服务卡片 → 服务详情页 → 查看图片和描述
```

### 2. 用户预约流程
```
服务详情页 → 点击"立即预约" → 选择/新增地址 → 填写期望价格和备注 
→ 上传现场图片 → 提交预约 → 生成工单
```

### 3. 地址管理流程
```
个人中心 → 地址管理 → 查看列表 → 新增/编辑/删除地址 → 设置默认地址
```

### 4. 工单查看流程
```
个人中心 → 我的工单 → 查看列表 → 状态筛选 → 点击查看详情 → 取消工单
```

## 🔧 技术亮点

### 1. 后端架构
- **分层架构**: Controller → Model → Database
- **统一响应格式**: `{ success, data, message }`
- **JWT认证**: 保护需要认证的接口
- **事务处理**: 工单创建使用事务保证数据一致性
- **权限控制**: 用户只能操作自己的数据

### 2. 前端设计
- **组件化**: 可复用的卡片组件
- **状态管理**: 统一的加载和错误状态
- **用户体验**: 下拉刷新、上拉加载、空状态提示
- **表单验证**: 完善的输入验证和错误提示
- **图片处理**: 支持选择、预览、删除

### 3. 数据库设计
- **范式化**: 符合第三范式
- **外键约束**: 保证数据完整性
- **索引优化**: 常用查询字段建立索引
- **快照机制**: 工单保存地址快照，防止数据变化影响历史记录
